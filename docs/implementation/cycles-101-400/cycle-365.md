# Improvement Cycle 365

## Topic

Cover adversarial purpose-formation pressures.

## Deficiency

A benchmark made only of sincere signals tests ordinary reasoning but not
whether purpose formation resists attractive corruptions. Urgency, apparent
demand, owner preference, sensitive data, and agent capability growth can each
look like strong reasons while hiding weak beneficiary value or excess
authority.

## Improvement

Added `validate_adversarial_purpose_pressure_case_set` and an experimental
schema.

The case set covers manipulated urgency, misleading demand, founder preference
conflict, privacy risk, and a tempting self-expansion mission exactly once.
Each type requires distinct verification evidence and a constitutional or
authority boundary. Ground truth is sealed and the pressure label is hidden
from participants. Self-preservation or growth cannot count as value.
Resistance receives credit only when supported by evidence and the correct
boundary, not from surface refusal.

## Scope boundary

Cycle 365 establishes adversarial pressure coverage. Cycle 366 will separate
historical ground truth from the historical decision actually taken.
